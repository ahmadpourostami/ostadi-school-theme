مجموعه المان‌های فارسی و RTL برای سایت اساتید آموزشی.

== امکانات ==
- پست‌تایپ اختصاصی ویدئو و پادکست
- دسته‌بندی و برچسب اختصاصی
- URL و مدت زمان رسانه
- المان Elementor با ویترین مقالات نزدیک به تصاویر رفرنس
- بلوک‌های Gutenberg برای مقاله، ویدئو، پادکست و ویترین
- طراحی RTL و ریسپانسیو

== Elementor ==
بعد از فعال‌سازی Elementor، دسته «المان‌های استادی ۱.۰» و المان «ویترین مقالات استادی» در Elementor اضافه می‌شود.
