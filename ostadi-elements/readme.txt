مجموعه رایگان المان‌های فارسی و RTL برای ساخت سایت اساتید با Elementor و Gutenberg.

== Description ==
Ostadi Elements یک افزونه است، نه قالب وردپرس. این افزونه مجموعه‌ای از المان‌ها و بلوک‌های طراحی برای اساتید و مدرس‌ها فراهم می‌کند.

== Installation ==
1. پوشه ostadi-elements را در مسیر wp-content/plugins/ قرار دهید یا نسخه ZIP را از بخش Releases نصب کنید.
2. افزونه را از صفحه Plugins فعال کنید.
3. برای Elementor، Elementor را نصب و فعال کنید.
4. برای Gutenberg نیازی به صفحه‌ساز اضافی نیست.
5. در Elementor دسته «المان‌های استادی» را انتخاب کنید.

== Current Widgets ==
Hero، عنوان بخش، کارت مقاله، شبکه مقالات، لیست دسته‌بندی، کارت ویدئو، کارت پادکست و کارت دوره.

== Requirements ==
WordPress 6.0+
PHP 7.4+
Elementor برای استفاده از Widgets آن.
