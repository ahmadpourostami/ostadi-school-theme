# Ostadi Elements

مجموعه رایگان المان‌های طراحی برای **اساتید و مدرس‌ها** با تمرکز روی ساخت سریع سایت‌های آموزشی با Elementor و Gutenberg.

> این پروژه یک قالب کامل وردپرس نیست. هدف پروژه، ارائه یک Design System و مجموعه‌ای از المان‌های قابل استفاده در صفحه‌سازهاست تا هر استاد بتواند سایت خودش را با آزادی عمل بالا بسازد.

## جهت پروژه

طراحی بصری پروژه از نمونه‌های ارسالی الهام می‌گیرد: کارت‌های مقاله، شبکه محتوا، دسته‌بندی‌ها، بخش‌های ویژه، و در ادامه المان‌های ویدئو، پادکست و دوره.

## نسخه فعلی

### Elementor
- عنوان بخش استادی
- کارت مقاله
- شبکه مقالات
- لیست دسته‌بندی مقالات
- دسته اختصاصی `المان‌های استادی`

### Gutenberg
- عنوان بخش استادی
- کارت مقاله
- شبکه مقالات
- لیست دسته‌بندی

## مسیر توسعه

1. کامل‌کردن Design System و کنترل‌های رنگ، فاصله، تایپوگرافی و Border Radius.
2. اضافه‌کردن Hero/Featured Article و اسلایدر مقالات.
3. المان‌های ویدئو، پادکست و دوره‌های Tutor LMS.
4. المان‌های نویسنده/مدرس، معرفی استاد و شبکه مدرس‌ها.
5. قالب‌های آماده برای صفحات خانه، آرشیو مقاله و صفحه مدرس.
6. سازگاری دقیق‌تر با موبایل و RTL.
7. بسته‌بندی و انتشار نسخه رایگان قابل نصب برای اساتید.

## ساختار

تمام قابلیت‌های جدید باید در پوشه `ostadi-elements/` توسعه پیدا کنند تا پروژه از یک Theme به یک **Elements Plugin** مستقل تبدیل شود.
